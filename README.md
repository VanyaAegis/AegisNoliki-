# 🎮 AegisNoliki

**AegisNoliki** — игра с онлайн-режимом и различными игровыми режимами.

## ✨ Возможности

* 🤖 Игра против ИИ
* 🌐 Онлайн-матчи
* 🎮 Различные игровые режимы
* 🎨 Настройка интерфейса и фонов
* 🎵 Музыка и звуковые эффекты

## 💻 Установка

1. Скачай установщик из раздела **Releases**.
2. Запусти `AegisNoliki_Setup_1.1.0.exe`.
3. Установи игру и запусти её с рабочего стола.

Python и PyCharm для запуска не нужны.

## 🖥️ Платформа
